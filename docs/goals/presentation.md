# What Will Impress at the Presentation

## 1. A live "agent brain" screen

While we talk to the agent, the screen shows:

- each tool it calls
- its plan
- how long each step took

The audience can *see* the agent think, not just hear it.

## 2. A manager page

- the refund approval list (Approve / Reject)
- call summaries
- test scores

## 3. Real numbers

We run 30+ test calls automatically, using text instead of voice so it's fast.
We show:

- the success rate
- the speed (how long until the agent starts speaking)
- both of these **with and without** each feature (reflection, tools, the
  agent team)

## 4. Diagrams in the professor's color style

The professor uses the same colors in every chapter:

| Color | Means |
| --- | --- |
| Red | Inputs (what comes in, like the customer's question) |
| Gray | The AI |
| Green | Tools and plain code |

Our architecture diagrams use these colors too.

## 5. Explain our choices

For each design choice, say *why*, using the course:

- why the first steps are fixed in code (predictable, Chapter 1)
- why reflection is only used in a few places (voice is time-sensitive, Chapter 2)
- why we use the supervisor setup (best for companies, Chapter 5)
